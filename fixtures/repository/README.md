# Orchestration Runtime fixture repository skeleton

This directory is the source-controlled skeleton for the dedicated Git fixture used by M4/M6.
M1 establishes scenario inventory only; it does not claim remote branch/PR/merge effects.

Planned controlled scenarios:
- GREEN check path
- RED check path
- merge conflict pair
- isolated worktree/subbranch path
- immutable review subject
- evidence-schema fixture
- fault injection: post-commit/pre-result, transport cut, merge-no-readback

A later granted fixture-repository operation may materialize these into actual branches/checks.
